## 운영 상태와 차단 사항

**이 노트 릴리스는 아직 VPS에 배포되지 않았다.** 준비한 정확한 대상은 `haar-workspace-mvp` 단일 서비스, 위 기능 커밋, 기존 SQLite에 `note_pages`/`note_commands`와 작업 인덱스를 추가하는 변경이다. 외부 접근이나 다른 서비스 변경은 배포 범위에 없다.

배포 요청은 자동 승인 검토에서 거절됐다. 사유: 구현 승인은 확인되지만 이번 노트 릴리스의 프로덕션 배포·서비스 재시작 명시 승인이 확인되지 않음. 거절은 명령 실행 전에 발생했으므로 이 시도의 전송·새 서버 디렉터리·백업·DB/코드 변경·재시작은 수행되지 않았다. 새 승인 근거 없이 재시도하지 않는다. 사용자의 정확한 배포/단일 재시작 승인이 필요하다.

마지막 읽기 전용 확인에서 운영 코드는 `758a22272a49303115f8f15c1e9fe788d6cc7fe1`, 작업대장 revision 10/28건, 서비스 active/running·NRestarts 0, dispatch 비활성이다. 기존 자동 전달 worker와 SSH 터널은 유지한다. 준비한 배포 검증은 일관 백업, 기존 11개 테이블 보존(정상 heartbeat 시각만 비교에서 명시 제외), unit/자원 제한·기존 자산 불변, 실패 시 코드만 복귀를 포함한다. 운영 실행 증거로 오인하지 않는다.

외부 HTTPS/모바일 접속도 별도 승인 대기다. 기존 Caddy/접근 통제를 읽기 전용 조사했고, 인증 없는 공개 노트·새 계정·DNS·TLS·프록시·방화벽 변경은 하지 않았다. 현재 SSH localhost 주소는 해당 터널이 있는 Mac 전용이며 iPhone 공개 접속 주소가 아니다.

증거는 X9 Pro 전용 작업 폴더의 `output/notes/`에 보존한다. `python-tests.txt`, `node-tests.txt`, `browser-functional-evidence.json`, `check-target-proof.json`, `render-checks.json`, `finish-review.md`, 데스크톱/모바일 캡처와 미실행 배포 묶음을 포함한다. 가상 검증 노트는 실제 운영 자료와 분리했다.
