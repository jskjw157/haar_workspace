# 부모 이벤트 자동 전달 운영 검증

검증일: 2026-10-19. 운영 기능 커밋 `758a22272a49303115f8f15c1e9fe788d6cc7fe1`. PR #3 기능 위의 후속 변경이다.

## 구현·테스트·운영 상태

- 구현 완료: 부모 변경 API, 단일 운영 원본 revision, 안정 이벤트/멱등 키, 전역 revision·작업 해시·검증 시각 검사, 감사 이력, 외장 outbox·자동 전송 worker·재시도·충돌 보류, 5초 화면 변경 감지, 30초 heartbeat/90초 연결 미확인, 입력 보존.
- 테스트 완료: Python 35개, 화면 상태 테스트 13개. 실제 격리 HTTP 서버에서 오프라인 큐 재시작 후 복구, 서버 반영 후 응답 유실 재시도의 중복 방지, 충돌 보류를 확인했다. 동시 이벤트 단일 승자, 오래된 근거·보호 필드 차단, Origin/본문 경계, 자동 감지 타이머, 구버전 렌더/작성 중 입력 보존도 포함한다. 기능 부재 실패 후 구현 통과를 확인했다.
- 운영 반영 완료: 일관 백업 후 HAAR 단일 서비스만 재시작했다. 기존 9개 테이블(초기 intake·기존 register)의 전체 스키마/행/user_version 해시가 배포 전후 동일했다. 두 이벤트용 테이블만 추가했다. unit 파일·격리·128MiB/32 Tasks 한도, 공통 스타일·홈 JavaScript·8개 이미지·백업 스크립트는 유지했다. 다른 서비스/에이전트/디자인은 변경하지 않았다.
- 실제 자동 반영 확인: 진행 중인 연동 작업 1건의 관측을 outbox에 enqueue했다. worker가 자동 전송했고 열린 브라우저가 페이지 새로고침 없이 revision 9와 새 상태를 표시했다. 동일 `performance.timeOrigin`과 문서 표식이 유지됐다. 이어 검증 완료 관측도 같은 경로로 전송해 revision 10을 확인했다. 수동 import는 사용하지 않았다.
- 28건 ID/상태를 API와 화면에서 대조했다. 변경한 1건의 허용 필드와 새 관측 근거 외에는 다른 행·우선순위·승인 범위·지시·완료 기준·기타 확장 필드가 초기 원본과 같았다. 검증 시각은 실제 관측만 갱신했다. 초기 Library 버전은 8로 보존하며 운영 revision 10과 구분한다.
- 1440×1000·390×844 운영 캡처 확인: 가로 넘침 없음, 계산된 텍스트 대비 위반 없음, 모바일 첫 화면에 첫 작업 ID/상태/제목 표시. 자동 반영 검증용 탭은 닫고 전송 worker와 기존 경로의 SSH 터널은 유지했다.

## 접속과 계속 사용하는 방법

접속은 기존 SSH localhost 경로의 [작업대장](http://127.0.0.1:3311/register)이다. 해당 터널이 있는 Mac 주소이며 인터넷/iPhone 공개 주소가 아니다.

부모는 **앞으로 실제 상태를 확인할 때마다** [갱신 프로토콜](REGISTER_EVENTS.md)의 draft JSON을 X9 Pro에 만들고 `app.publisher enqueue --file ...`로 같은 outbox에 기록해야 한다. 이후 전송·재시도·대시보드 감지는 자동이다. Library 파일만 고치거나 다른 세션에서 대화한 사실을 시스템이 독립적으로 알아내지는 않는다. Library 상시 수집/다른 AI 실행 관찰/실제 작업 dispatch는 미연결이다. 기능 완료와 이 연결 한계를 구분한다.

worker와 SSH 터널은 이번 실행에서 동작하는 프로세스다. 새 로그인/부팅 자동 실행 설정·키·OAuth·영구 권한은 만들지 않았다. Mac 종료/재부팅이나 helper 종료 후에는 기존 터널과 문서의 watch 명령을 다시 실행해야 한다. 대기열은 X9 Pro에 남고 90초 접촉 지연은 화면에서 확인할 수 있다. 외장이 없으면 내장으로 대체하지 않는다.

실제 원본·행 내용·캡처·private queue·상세 영수증은 공개 Git에 없다. X9 Pro의 `repo/output/events/`에 배포 영수증, 테스트 로그, `live-auto-update.json`, `production-ui-evidence.json`을 보관한다. 백업과 이전 VPS 코드 릴리스도 보존한다.

## 자동 구간과 부모의 필수 입력

| 단계 | 현재 동작 | 자동 여부 |
| --- | --- | --- |
| 초기 출처 | 확인한 Library JSON v8, 28건. 원본을 자동 감시하지 않음 | 최초 안전 import만 수행 |
| 실제 관측 기록 | 부모가 상태와 근거·확인 시각을 검증하고 X9 JSON 작성 후 `app.publisher enqueue --file ...` | 부모의 명시적 기록 동작 필요 |
| 전송 | X9 SQLite outbox를 worker가 확인, 기존 SSH API로 전송·지수 재시도·409 보류 | enqueue 이후 자동 |
| 중앙 저장 | VPS에서 revision/작업 해시/확인 시각을 검사하고 원장·영수증·감사 이력 원자 저장 | 수신 후 자동 |
| 화면 반영 | 5초 revision/cursor 조회, 변경 시 대장 재조회와 입력 보존 | 화면이 열린 동안 자동 |

실제 검증 작업은 HAAR-020 한 건이다. 2026-10-19 11:36:34 UTC에 실행 확인 관측이 revision 9로, 11:38:01 UTC에 완료 검증 관측이 revision 10으로 반영됐다. 같은 열린 문서의 timeOrigin과 표식을 유지해 수동 새로고침이 없음을 확인했다. 이 시각은 작업 변경 성공 시각이며 이후 30초 heartbeat와 구분한다.

부모가 Library나 대화에만 상태를 적고 enqueue하지 않으면 이 경로로 반영되지 않는다. 다른 GPT/dot/AI 런타임 관측, Library 상시 수집과 부모 도구 호출의 자동 후킹은 미연결이다. 화면 폴링만을 전체 자동 추적으로 표현하지 않는다. Mac 재부팅·worker 중단 뒤 watch/기존 SSH 터널 재실행도 수동이다.

후속 운영 확인: 2026-10-19 12:43:52 UTC, 노트/인증 HTTPS 배포를 실제 검증한 관측을 HAAR-020에 enqueue했다. worker가 수동 flush 없이 revision 11로 반영했다. 기존 완료 상태·보호 필드는 유지했다. 가장 최근 실제 변경 성공이며, heartbeat 시각과 구분한다.
