# HAAR Workspace

여러 AI와 기기에 분산된 HAAR 쇼핑몰 업무를 **지시 → 실행 → 검토 → 승인 → 결과 추적**으로 연결하기 위한 제품 기획 저장소입니다.

첫 제품은 VPS의 반응형 웹이며, iPhone에서는 같은 웹으로 우선순위를 정하고 AI에 지시하고 결과를 검토합니다. 각 실행 환경의 adapter 개발도 제품 범위입니다. 중앙 VPS는 화면·기록·지시 전달을 맡고 이미지·브라우저 연산은 실행 노드가 처리합니다. MCP를 연결했다는 이유로 기존 AI 대화가 자동 실행되지는 않습니다.

**현재 상태: PRD 초안 / 구현 전.** SELLAYER와 별도 프로젝트입니다. 이번 변경에는 구현 코드, 서비스 설치, 배포, 기존 서버 변경, 비밀정보 이관이 없습니다. 기존 서버의 Paperclip 설치 상태도 미검증입니다.

제품 범위는 PRD, 화면 흐름은 화면설계, 구성은 TDD, 필드/명령 계약은 데이터/API/MCP 명세, 권한은 보안설계, 순서/추적은 구현계획을 기준으로 합니다. 기존 PRD의 화면·데이터 개요는 유지하고 상세 정의를 중복 복사하지 않습니다. 문서 보강 승인은 앱 구현·배포·PR 병합 승인이 아닙니다.

## 검토할 핵심 결정

- Paperclip의 실제 작업 배정·진행 상태·실행기록 로직을 분석해 재사용하고 단일 작업 상태를 유지합니다.
- Buzz는 대시보드 안에서 담당 AI에게 일을 요청하고 답변과 결과물을 받는 채팅창입니다. 작업 상태와 실제 실행을 연결하는 방법은 뒤의 기술설계에서 설명합니다.
- 대상은 VPS Hermes·OpenClaw, Mac의 COKACDIR·Orca, GPT의 다섯 경로입니다. VPS의 Hermes와 OpenClaw는 사용자가 확인한 대상이며, 실제 설치·버전·API/CLI 지원 검증은 별개입니다. COKACDIR는 공식 저장소와 Mac 읽기 조사로 명칭·CLI 실행 경로를 확인했으며, 정확한 버전·세션 연동 API는 미확인입니다. Orca의 정확한 제품명과 GPT 호출 방식은 추가 확인합니다.
- Argo의 공개된 기억·인계·AI 카드·스킬 UX를 참고해 독자 구현합니다. Argo 코드는 재사용하지 않습니다.
- 홈은 오늘 집중 최대 3개, 우선순위, 마감, 승인 대기 결과물, 막힌 일과 진행 그래프를 먼저 보여줍니다.
- 원본과 결과는 SKU·버전·Drive 참조·검수 이력을 연결합니다. 확인되지 않은 상품 스펙을 게시하지 않습니다.
- 초기에는 기록·검토·지시를 완성하고, 실제 게시·광고 예산 변경·CS 발송은 명시적인 승인 계약이 검증된 다음 단계로 둡니다.

문서의 **[확정]**은 전달받은 사용자 합의, **[제안]**은 구현 전 검증할 설계, **[미확인]**은 추가 확인이 필요한 사실을 뜻합니다. 숫자 목표와 엔드포인트 예시는 모두 제안이며 현재 동작을 뜻하지 않습니다.

## 변경 원칙

새로운 결정은 근거·작성일·적용 범위와 함께 기록하고 관련 수용기준을 함께 수정합니다. 실제 상품 원본, 고객정보, 비공개 Drive 링크, 계정·비밀번호·토큰·CSV는 이 공개 저장소에 넣지 않습니다. 예시는 가상의 식별자만 사용합니다.
