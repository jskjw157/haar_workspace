# HAAR Workspace

여러 AI와 기기에 분산된 HAAR 쇼핑몰 업무를 **지시 → 실행 → 검토 → 승인 → 결과 추적**으로 연결하기 위한 제품 기획 저장소입니다.

첫 제품은 VPS의 반응형 웹이며, iPhone에서는 같은 웹으로 우선순위를 정하고 AI에 지시하고 결과를 검토합니다. 각 실행 환경의 adapter 개발도 제품 범위입니다. 중앙 VPS는 화면·기록·지시 전달을 맡고 이미지·브라우저 연산은 실행 노드가 처리합니다. MCP를 연결했다는 이유로 기존 AI 대화가 자동 실행되지는 않습니다.

**현재 상태: M0 작업 정리 체험판.** SELLAYER와 별도 프로젝트입니다. Today 보드·초안 영속 저장·집중 3개·우선순위/마감·수동 결과 검토·인계 기록이 동작합니다. Paperclip 원장, Buzz 채팅, AI 자동 실행은 미연결입니다. 기존 문서는 사용자 승인된 전체 제품 설계이며, 아래 체험판의 현재 구현 범위와 구분합니다.

[중앙 작업대장 연결](docs/REGISTER_SYNC.md)은 Library JSON 확인본의 안전 import, `/register` 조회·60초 화면 갱신, 버전 기반 반영 대기 제안과 JSON/MD 내보내기를 제공합니다. VPS의 Library 상시 자동 수집·양방향 자동 반영은 미연결입니다. 기존 디자인 수정 정지와 별도 변경이며 새 인증·실행 권한을 추가하지 않습니다.

## 바로 실행

Python 3.12 이상, 추가 패키지 없음.

```sh
python3 -m app.server --port 3310
```

[로컬 작업실](http://127.0.0.1:3310)에서 시작합니다. DB는 `.data/workspace.sqlite3`에 저장되고 예시는 명시적으로 추가해야 합니다. 공개 인터넷에 열지 마세요. VPS 접속은 기존 SSH 터널을 사용합니다.

```sh
ssh -N -L 127.0.0.1:3311:127.0.0.1:3310 vps
```

터널 연결 후 [VPS 작업실](http://127.0.0.1:3311) 접속. 실제 iPhone 원격 접속에는 별도 인증된 접근 경로가 필요하며 아직 제공하지 않습니다.

[실행·운영 안내](docs/MVP_RUNBOOK.md)와 [검증 기록](docs/MVP_VERIFICATION.md)에서 실제 설치 점검 결과, 기능 경계, 보안, 백업, 테스트와 후속 차단 사항을 확인합니다. Paperclip은 확인한 VPS 경로에서 서버를 찾지 못했고 Buzz는 중지 상태라 기존 서비스·데이터를 변경하지 않았습니다. 이 체험판은 Paperclip 등록 전 초안을 보관하며 별도 실행 scheduler나 task 상태 원장을 만들지 않습니다.

## 현재 화면의 디자인 기준

[DESIGN.md](DESIGN.md)는 실제 색·타이포그래피·간격·공통 컴포넌트와 반응형 규칙, [PRODUCT.md](PRODUCT.md)는 보존할 제품 사실을 담습니다. [디자인 스킬 설치·적용 기록](docs/DESIGN_SKILLS.md)에서 두 스킬의 공식 소스·고정 커밋·개인 설치 범위·인식 검증을 확인할 수 있습니다.

[일러스트 적용 기록](docs/ILLUSTRATIONS.md)에 오늘 집중·빈 목록·결과 검토·연결 대기의 이미지 원본, 생성 프롬프트, 경량화와 화면 검증 범위를 기록합니다. 해당 변경의 로컬 검증과 실제 서버 반영 여부는 구분합니다.

[스튜디오 팔레트·메뉴 배너](docs/STUDIO_REFRESH.md)는 후속 사용자 요청으로 추가한 네 메뉴의 배너 원본·프롬프트, 공통 색상 토큰과 전 메뉴 검증을 기록합니다. 기존 작은 일러스트와 작업 행 구조를 보존하고 밝은 패션·주얼리 작업실 톤을 적용합니다.

## 검토할 핵심 결정

- Paperclip의 실제 작업 배정·진행 상태·실행기록 로직을 분석해 재사용하고 단일 작업 상태를 유지합니다.
- Buzz는 대시보드 안에서 담당 AI에게 일을 요청하고 답변과 결과물을 받는 채팅창입니다. 작업 상태와 실제 실행을 연결하는 방법은 뒤의 기술설계에서 설명합니다.
- 대상은 VPS Hermes·OpenClaw, Mac의 COKACDIR·Orca, GPT의 다섯 경로입니다. VPS의 Hermes와 OpenClaw는 사용자가 확인한 대상이며, 실제 설치·버전·API/CLI 지원 검증은 별개입니다. COKACDIR는 공식 저장소와 Mac 읽기 조사로 명칭·CLI 실행 경로를 확인했으며, 정확한 버전·세션 연동 API는 미확인입니다. Orca의 정확한 제품명과 GPT 호출 방식은 추가 확인합니다.
- Argo의 공개된 기억·인계·AI 카드·스킬 UX를 참고해 독자 구현합니다. Argo 코드는 재사용하지 않습니다.
- 홈은 오늘 집중 최대 3개, 우선순위, 마감, 승인 대기 결과물, 막힌 일과 진행 그래프를 먼저 보여줍니다.
- 원본과 결과는 SKU·버전·Drive 참조·검수 이력을 연결합니다. 확인되지 않은 상품 스펙을 게시하지 않습니다.
- 초기에는 기록·검토·지시를 완성하고, 실제 게시·광고 예산 변경·CS 발송은 명시적인 승인 계약이 검증된 다음 단계로 둡니다.

문서의 **[확정]**은 전달받은 사용자 합의, **[제안]**은 구현 전 검증할 설계, **[미확인]**은 추가 확인이 필요한 사실을 뜻합니다. 숫자 목표와 엔드포인트 예시는 모두 제안이며 현재 동작을 뜻하지 않습니다.

## 변경 원칙

새로운 결정은 근거·작성일·적용 범위와 함께 기록하고 관련 수용기준을 함께 수정합니다. 실제 상품 원본, 고객정보, 비공개 Drive 링크, 계정·비밀번호·토큰·CSV는 이 공개 저장소에 넣지 않습니다. 예시는 가상의 식별자만 사용합니다.
